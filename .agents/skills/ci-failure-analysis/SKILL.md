# CI 실패 분석

1. 실패 로그에서 최초 실패 지점과 재현 명령을 확인합니다.
2. 실패를 테스트, 컴파일, 빌드, 환경 문제 중 하나로 분류합니다.
3. 원인 파일과 원인 코드를 찾고, 승인된 범위 안의 최소 수정안을 제시합니다.
4. 실패 테스트 삭제·비활성화, 검증 완화, 무관한 리팩터링으로 우회하지 않습니다.
5. 수정 후 실패한 검증과 연관된 검증을 다시 실행합니다.
6. 최종 보고에 원인, 수정 내용, 실행한 명령과 남은 환경 의존성을 기록합니다.
